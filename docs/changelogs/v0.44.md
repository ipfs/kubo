### 🔦 Highlights

#### 💾 `ipfs add --nocopy` asks for a restart instead of copying

Turning on [`Experimental.FilestoreEnabled`](https://github.com/ipfs/kubo/blob/master/docs/experimental-features.md#ipfs-filestore) or [`Experimental.UrlstoreEnabled`](https://github.com/ipfs/kubo/blob/master/docs/experimental-features.md#ipfs-urlstore) takes effect only after the daemon restarts. Until now, `ipfs add --nocopy` against a daemon started before that change silently copied the data into the blockstore. It now fails with an error that asks you to restart the daemon.

#### 📦️ Dependency updates

- update `go-libp2p` to [v0.50.0](https://github.com/libp2p/go-libp2p/releases/tag/v0.50.0)
- update `go-ds-pebble` to [v0.5.13](https://github.com/ipfs/go-ds-pebble/releases/tag/v0.5.13)
