### 🔦 Highlights

#### 🐛 Provider keystore no longer leaks when `Routing.Type=none`

When `Routing.Type` is `none` (or a node is built with the nil router), Kubo creates no DHT provider, but the provider keystore under `<repo>/provider-keystore/` still opened its datastore and never closed it. The leaked datastore kept its lock, so reopening the same repo in the same process failed (for example `resource temporarily unavailable` on Linux or `being used by another process` on Windows). This only affected software that embeds Kubo and restarts a node in-process (the `ipfs daemon` CLI was unaffected because the process exit released the lock). The keystore is now closed on every path that does not hand it off to a provider.

#### 📦️ Dependency updates

- update `go-libp2p` to [v0.50.0](https://github.com/libp2p/go-libp2p/releases/tag/v0.50.0)
