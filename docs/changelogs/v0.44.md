### 🔦 Highlights

#### 🧯 Negative optional byte sizes are rejected instead of crashing

Config keys typed as `optionalBytes`, such as `Import.UnixFSHAMTDirectorySizeThreshold`, `Gateway.MaxRangeRequestFileSize`, and `Swarm.ResourceMgr.MaxMemory`, accepted a negative number when it was written as a JSON number instead of a string. The value was stored and then failed to parse later, which crashed the command using it with a `panic: invalid byte size` stack trace, including `ipfs add` and `ipfs daemon`.

Negative numbers and values too large to represent are now rejected with a normal config error at load time, matching the behavior that already applied to string values. `ipfs config --json Import.UnixFSHAMTDirectorySizeThreshold -- -1` now fails cleanly and leaves the config unchanged.

#### 📦️ Dependency updates

- update `go-libp2p` to [v0.52.0](https://github.com/libp2p/go-libp2p/releases/tag/v0.52.0)
- update `go-ds-pebble` to [v0.5.13](https://github.com/ipfs/go-ds-pebble/releases/tag/v0.5.13)
